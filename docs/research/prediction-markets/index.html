What the result shows

One local Qwen 3.5 9B configuration correctly separated transparent informative and manipulated endpoints when deterministic code handled the arithmetic.

What it does not show

It does not establish that LLMs generally resist manipulation or can identify why a price moved in a real market.

Experimental design

Hold the quote fixed. Change only where it came from.

Twelve neutral fictional events avoid historical knowledge. Each event appears in three matched source conditions, producing 36 independent, stateless decisions.

Evidence audit

The endpoint result is reproducible; the broader claim is not established.

The completed log supports the transparent-credibility result. The later v0.4 archive adds a frozen graded experiment but contains no model outputs from that experiment.

Available and verified

  • 36 append-only raw JSONL decisions with exact prompts
  • 36 successful parses and zero retries
  • Prompt hashes match the frozen protocol
  • Analysis regenerates from the raw log
  • v0.4 code passes 43 automated tests
  • Frozen 60-case gradient file validates exactly

Not established yet

  • No executed results for the 60-call credibility gradient
  • No replication across prompt templates or model families
  • No real-market or multi-agent evidence
  • Raw outputs from the original 48-call pilot were not recovered
  • Raw outputs from the 24-call competence diagnostic were not recovered
Current conclusion

The transparent endpoints passed a manipulation check. The result is useful because it justifies a harder experiment, not because it proves robust manipulation resistance.

Next experiment · Protocol frozen

Exact calculator benchmark

For a 0.80 quote, LR(α) = (0.50 + 0.30α) / (0.50 − 0.30α); a 0.20 quote uses its reciprocal.
