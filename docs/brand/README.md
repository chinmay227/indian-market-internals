# CMB Research visual mark

The site mark is intentionally restrained: a partial **C** around three ascending research/data bars, using the publication's navy and muted teal palette.

Primary asset: `/assets/favicon.svg`

The same mark is used as the browser favicon and a subtle header mark. It is designed to remain legible at very small sizes and avoids trading-specific imagery such as candlesticks, arrows, bulls, or bears.
